# HYDROS Human-Governed Agentic Architecture

**Doctrine version: 2026-09-12**

HYDROS applies the Avanyu control model to water-rights and water-intelligence systems.

**AI supplies velocity. People retain authority.**

**Client → Contract → Scope → Policy → Identity → Agent → Evidence → Human Authority → Client**

Agents may assist with document intelligence, GIS analysis, research, workflow, software engineering, security and operational analysis. Regulatory determinations, water-right decisions and other consequential judgments remain with authorized people.

## Authorization tiers
Tier 0 Observe; Tier 1 Recommend; Tier 2 Generate without execution; Tier 3 Human-approved execution; Tier 4 narrowly pre-authorized, reversible, low-blast-radius autonomous actions with complete logging and rollback.

RAG context is not authority. Source provenance, confidence, human review, audit evidence, security and recovery are part of the architecture.
