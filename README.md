# HYDROS

**New Mexico Digital Water Platform prototype**

HYDROS is a public-first homepage concept for a modern decoupled water information platform. This static prototype demonstrates the intended React/Drupal experience while remaining immediately deployable through GitHub Pages.

## Prototype features

- Public task dashboard
- Water Stories content model
- Read-only GIS dashboard concept
- Interactive historical timeline
- Search, payments, language-access, and service-flow demonstrations
- Responsive and keyboard-friendly interface
- Clear prototype notices to avoid confusion with official services

## Preview locally

Open `index.html` in a browser, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

Open **Settings → Pages** and choose:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**

Expected URL:

`https://gavinlujan42-glitch.github.io/HYDROS/`

## Production evolution

The next implementation layer can replace static data with React, Drupal JSON:API, ArcGIS Online, OCR/OpenSearch, hosted PCI-compliant payment pages, enterprise identity, RBAC, and managed Spanish translations.

## Status

Design prototype only. It does not provide official records, payments, applications, or agency services.
